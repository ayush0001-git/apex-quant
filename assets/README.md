# Apex Quant Visual Assets

This directory contains visual documentation and performance proofs for the Apex Quant Terminal:

- `terminal_demo.gif`: Live animated recording of the interactive TradingView Lightweight Charts terminal with bracket execution overlays.
- `equity_curve.png`: 24-month out-of-sample backtest equity curve comparing Apex Quant (CAGR 24.6%, Sharpe 1.42) against NIFTY 50 benchmark.
- `swagger_docs.png`: Self-documenting FastAPI REST & WebSocket endpoint catalog.
- `terminal_preview.png`: High-resolution dark-mode terminal layout preview.
- `social_preview.png`: OpenGraph and repository preview banner.
